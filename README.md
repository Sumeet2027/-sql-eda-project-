# 📊 SQL Data Analysis Project

## 📌 About the Project

This project is about analyzing sales data using **SQL Server**.

The main goal is to explore the data, find important information, and answer business questions using SQL queries.

---

## 🛠️ Tools Used

* SQL Server
* SQL
* SQL Server Management Studio (SSMS)

---

## 📂 Project Steps

```text
1. Import Dataset
2. Explore Data
3. Analyze Data
4. Answer Business Questions
5. Find Business Insights
```

---

## 📊 Analysis Performed

### 🔹 Revenue Analysis

* Total revenue
* Revenue by category

### 🔹 Product Analysis

* Top 5 products by revenue
* 5 lowest-performing products

### 🔹 Customer Analysis

* Top 10 customers by revenue

---

## ❓ Business Questions

* What is the total revenue?
* What is the total quantity sold?
* What is the revenue generated by each category?
* Which 5 products generate the highest revenue?
* Which 5 products have the lowest sales?
* Which 10 customers generate the highest revenue?

---

## ▶️ How to Run

1. Open **SQL Server Management Studio**
2. Create or select your database
3. Import the dataset
4. Run the SQL queries
5. Check the results
6. Use the results to understand the business performance
